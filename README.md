# StaffFrame 谱线校读台

把拍下的单段高音谱表用于排练前的纸上音符核对。左上角是像素原点，X 向右、Y 向下，第一线指纸上最上面一线。校读只给高音谱表的自然音位置，调号、临时记号、演奏移调与时值另按原谱。

1. 打开明确标为合成的练习谱页，或导入一张单帧 PNG、JPEG、TIFF、BMP 或 WebP。
2. 填写谱段左右端、上侧第一线与线距。可以在原片点读，也可以用「选音符」填写实际坐标。
3. 点「保存并校读」确认写谱位置与原列亮度，再从校读卡菜单重开或下载带原片依据的 PNG、CSV、ZIP。
4. 校读卡会在所填左右端之内找选音两侧最近的实拍小节线。只有从左端附近贯通到第五线附近的竖墨才算；符干不算。两条贯通线相距不超过半个线距时按一道界处理，判音与裁边以靠本小节的那笔为准。任一侧缺失只提示复核，不补边。
5. 选音严格落在两条界之间才给本小节的音名，坐标始终是原片像素。校样上会标出这两道界与本段裁边；「小节 PNG」按这段裁切，裁边最多在对应小节线前后各挪四分之一线距，选音不会被裁掉。裁切多留的笔画不改变判音范围。
6. 需要进一步处理时，可把实际照片移交准备工作区。

`docker compose up --build -d --wait` 默认在本机 19912 端口启动。已有 Python 3.11 虚拟环境时，可安装 `requirements.txt` 并执行 `./start.sh`。运行数据留在 Compose 命名卷或普通启动的数据目录。
